# 翻訳文体と意味の保持

原文の各文で、何を・どの条件で・どの程度確かだとして述べているかを確認する。その関係を保持したうえで、日本語の述語に合う語順へ組み直す。形式主語、受動態、名詞化、著者を指すweを機械的に写さない。ただし、誰の行為・主張なのかが曖昧になる省略はしない。

長文は条件・理由・例外の掛かり先を保てる位置で分ける。単なる併記に「そのため」を足したり、目的を結果に変えたりしない。段落の順序や主張の比重は変えない。冗長な名詞の連続は動詞で開き、何が何に作用するのかを示す。

原則である調とし、「なのだ」「であります」などを混ぜない。「することが可能である」は文脈に応じて「できる」とする。canが能力なのか可能性なのかは区別する。「と言えるだろう」などの定型句で断定を弱めない。

## 確信度・条件・否定

次は固定訳ではない。主語、文脈、評価対象に応じて訳し、原文の強さを越えない。

| 原文の働き | 保持する区別 |
| --- | --- |
| may / might / could | 可能性・許容・過去の能力を区別する。可能性を確定した効果へ変えない |
| suggest / indicate | 示唆と観察上の裏付けを、証明に引き上げない |
| show / demonstrate | 実験で示した結果を不必要に弱めない。全入力の数学的証明とは限らない |
| prove / establish | 証明・確立の対象と成立条件を保持する |
| likely / possibly | 高い見込みと単なる可能性を区別する |
| approximately / at least / at most | 約・以上・以下を落とさず、超・未満と取り違えない |
| under the assumption that | 仮定の下での結果を無条件にしない |
| P only if Q | QはPの必要条件。PならQであり、逆方向を追加しない |
| P if and only if Q | 必要十分条件。片方向だけの条件にしない |
| not all / none / not necessarily | 部分否定、全否定、必然性の否定を区別する |

例：`The results suggest that caching may reduce latency under low load.`

訳例：「結果は、低負荷時にはキャッシュによって遅延を短縮できる可能性を示唆している。」

「キャッシュは遅延を短縮することが証明された」とはしない。原文に測定値や有意差がなければ追加しない。

専門用語の解説、研究背景、評価や感想、原文が述べない因果関係を補わない。原文の誤りが疑われる場合は、記載を保持し、利用に影響するときだけ本文外で照会事項にする。判読不能箇所は位置を示し、もっともらしい文章で埋めない。
